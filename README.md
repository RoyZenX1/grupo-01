# 🚀 Grupo 01 — Proyecto Web con JavaScript

## 📌 Descripción

Proyecto web desarrollado por el **Grupo 01** como parte del curso de **JavaScript**.

El objetivo del proyecto es aplicar los conocimientos adquiridos durante el curso en el desarrollo de una aplicación web utilizando tecnologías frontend y buenas prácticas de programación.

---

## 🎯 Objetivos

* Aplicar fundamentos de JavaScript.
* Desarrollar una interfaz web funcional.
* Implementar interacción dinámica con el usuario.
* Manipular el DOM mediante JavaScript.
* Organizar correctamente la estructura de un proyecto web.
* Utilizar Git y GitHub para el control de versiones.
* Trabajar colaborativamente mediante ramas.

## 🌿 Flujo de trabajo con Git

El proyecto utiliza ramas para organizar el desarrollo.

### Rama principal

```text
main
```

Contiene las versiones estables del proyecto.

### Ramas de desarrollo

Ejemplo:

```text
feature/nombre-funcionalidad
```

Para crear una nueva rama:

```bash
git switch -c feature/nombre-funcionalidad
```

Guardar cambios:

```bash
git add .
git commit -m "Descripción del cambio"
```

Subir la rama:

```bash
git push -u origin feature/nombre-funcionalidad
```
